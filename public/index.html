On the Stream Deck

A native Companion module with a start/pause toggle, nudges, set duration, rundown Prev / Take / Next, and live time and colour on the keys.

Whoever's best placed runs it

The switcher op backstage, the graphics op, the show caller at FOH or a dedicated operator: anyone with the control link can run the clock. Everyone else is in observer mode until they tap Take over, and every panel shows who's in control.

Run it from your phone

The live controls fit on one phone screen: timer, Start/Pause, Reset, ±1 and ±5. Changes wait as a draft until you Apply, so nothing reaches the screen by accident.

Real clocks as well as screens

A bridge drives CDEther / Hive LED displays from the same timer, so the lectern clock and the stage screen always agree.

Every breakout on one dashboard

Run all your rooms side by side. Each room gets its own secret control and display links, with no guessable room codes for the audience to find.

Talk to the stage, quietly

Send "Wrap up" or "Take questions" to the speaker, full screen or as a ticker, without touching the countdown. The display shows who's on and who's next from your rundown, so the speaker always knows where they are.

The details operators ask about.

What you'd want to know before trusting it with a keynote.

Duration or End at
Count down a length of time, or count to a clock time ("finish at 14:30"). The server keeps the time, so every screen agrees.
Rundown
Load a running order of speakers and session lengths, then use Prev / Take / Next. Speaker and "up next" lines appear on the display.
Warnings
Green, amber, red, then purple on overrun. You set the thresholds and colours per room.
Messages
Send "Wrap up" or "Take questions" to the stage, full screen or as a ticker. Clear it with one tap.
Clean output
Chromakey or any background colour, hide any element, and the timer fits to width on any screen, portrait or landscape.
Overrun & clock
Count up after zero, H:MM:SS past an hour, and a time-of-day clock mode for breaks.
Keyboard
Space to start or pause, R to reset, +/- to nudge, and arrows and Enter to work through the rundown.
Survives restarts
Rooms and timer state are saved, so a server restart picks up where it left off.
