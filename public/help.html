Getting started

Each room is one timer, usually one per stage or breakout. Every room has two secret links:

  • Control link: for the operator. Starts, pauses and sets the timer, and sends messages.
  • Display link: for the screen the speaker sees. It only shows the timer and can't change anything.

On the dashboard, press Share links & QR on a room to copy the links or show QR codes to scan. Treat the control link like a password: anyone who has it can run that room.

Two versions of the same timer exist:

  • Foxy Timer Online (foxytimer.com): runs on the internet; every device needs an internet connection.
  • Foxy Timer for Windows: runs on your show laptop; devices only need to be on the same network as the laptop, with no internet needed.

They're separate: a room made on one doesn't exist on the other.

Connecting phones & screens

With Foxy Timer Online, any device with internet can open the links.

With Foxy Timer for Windows, the laptop is the server. Phones, screens and the Stream Deck PC connect to the laptop across the venue network:

  1. Put every device on the same network as the laptop: same Wi-Fi, or the same switch.
  2. On the dashboard, press Share links & QR, then QR, and scan with the phone's camera.
  3. Open the Display link on the screen's computer, full screen.

The links look like http://192.168.1.13:3000/control?token=…. 192.168.1.13 is the laptop's address on that network; 3000 is the door Foxy Timer listens on. The This laptop panel on the dashboard shows the current address.

"localhost" only works on the laptop itself. It means "this computer", so a phone can't use it. The dashboard always gives links with the network address instead.

A phone or screen won't connect

The page usually just keeps loading and then gives up. Work through these in order:

1. Windows Firewall is blocking it (the most common cause)

Windows blocks other devices from reaching the laptop unless Foxy Timer is allowed through its firewall. It's especially likely when Windows has marked the Wi-Fi as a Public network, which is common at venues and even at home.

  • The dashboard's This laptop panel checks this and shows a warning. Press Allow through firewall and answer Yes to the Windows prompt.
  • The Foxy Timer installer sets this up for you. It's only needed with a hand-copied or older version.

2. A VPN is switched on

VPN apps (NordVPN, company VPNs) often cut the laptop off from other devices on the same Wi-Fi. Disconnect the VPN, or turn on its "allow local network" / "Invisibility on LAN" option.

3. The Wi-Fi keeps devices apart

Guest and venue Wi-Fi often uses client isolation: devices can reach the internet but not each other. No software can get round that. Use your own router or switch for the show network, or ask the venue for a network without isolation.

4. They're not really on the same network

Check the phone isn't on mobile data or a different Wi-Fi (e.g. a 2.4 GHz and a 5 GHz network with different names can be separate). If the laptop has several connections (Wi-Fi and cable), the This laptop panel lists every address; try the one on the same network as the phone.

5. The laptop's address changed

The router hands out addresses and can change them, e.g. after a restart. The old links then stop working. Open Share links & QR again for the new ones. On your own rig, giving the show laptop a fixed address avoids this.

Companion / Stream Deck

Foxy Timer works with Bitfocus Companion, so Stream Deck buttons can start, pause, nudge and step through the programme, and show live time and colour.

1. Install the module

Download the Foxy Timer Companion module (a small .tgz file; works with Companion 4). Then, on the PC running Companion:

  1. Open the Companion web page and go to Modules.
  2. Press Import module package and choose the downloaded .tgz file. Don't unzip it.
  3. Go to Connections, add a connection and search for Foxy Presentation Timer.
Updating? Download and import the new file the same way. If the connection still shows the old version, choose the new one in the connection's settings.

2. Fill in the connection settings

Server URL
Foxy Timer for Windows: copy it from the dashboard's Companion / Stream Deck window, e.g. http://192.168.1.13:3000. Foxy Timer Online: https://foxytimer.com.
Client API key
Windows: copy it from the same window. Online: Business Shows gives you your account's key.
Room IDs to monitor
The room names, exactly as on the dashboard, separated by commas, e.g. Main stage,Breakout 1. The Windows window lists them ready to copy.
Poll interval
Leave at 1000 ms (once a second).

The connection turns green when it can reach Foxy Timer. The Stream Deck PC must be on the same network as the laptop (Windows) or online (Online).

Foxy Timer for Windows

Start and stop

  • Start: the Foxy Timer icon on the desktop or Start menu. It starts quietly in the background and opens the dashboard in your browser.
  • Stop or restart: the This laptop panel on the dashboard. Closing the browser does not stop the timer, on purpose, so a show can't stop by accident.
  • Opening the icon again while it's running just reopens the dashboard.

On the laptop, no login

The dashboard opens without a login on the laptop itself. Other devices can only use the links you give them.

Where your rooms are kept

In your Windows user folder (%LOCALAPPDATA%\Foxy Timer\data). Updating or reinstalling Foxy Timer keeps them. A running timer carries on at the right time after a restart.

No internet needed

Nothing Foxy Timer for Windows does goes over the internet: the pages, the timer, the QR codes and Companion all work on the show network alone.

Control page tips

  • Duration or End at: count down a length of time, or to a clock time. Type a value and press Apply; nothing changes on screen until you do.
  • How it counts (next to Timer / Clock): Count down; Down, then up (carries on counting the overrun); or Count up (a stopwatch from 0:00).
  • Display Settings (bottom of the page): warning thresholds, colours (type a hex code or pick), background and chromakey, size, and what the screen shows, including time of day and finish time.
  • Several control panels: one is in control and the others watch (orange frame). Tap Take over to take control. A panel that drops out keeps its place for 30 minutes.
  • Keyboard: Space start/pause · R reset · + / - ±1 min (hold Shift for ±5).
