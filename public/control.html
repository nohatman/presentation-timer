Add to the running order
Time as MM:SS or minutes (20 means 20 minutes); leave it empty for 30:00. Enter adds it and clears the boxes for the next one.
Import a running order
One per line: the name, a comma, then the time, e.g. Jane Smith, 20:00 or Jane Smith, 20 for minutes. Cells copied from Excel or Google Sheets work too: name in one column, time in the next.
Export the running order
As text (Name, MM:SS per line) to paste anywhere and bring back with Import, or as a CSV file for a spreadsheet.
